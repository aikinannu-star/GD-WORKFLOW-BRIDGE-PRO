QUICK START (5 MINUTES)
================================================================================

1. DEPLOY
   - Copy plugin to /wp-content/plugins/
   - Or upload via WordPress admin

2. ACTIVATE
   - WordPress Admin → Plugins → Activate
   - Database tables auto-created

3. CONFIGURE
   - Go to GD Workflow → License
   - Create WooCommerce categories:
     * Physical Products
     * Digital Products
     * Services ← (Key category!)

4. CREATE SERVICE PRODUCT
   - Products → Add New
   - Assign to "Services" category
   - Set price

5. TEST
   - Place order with service product
   - Mark order as Completed
   - Check: GD Workflow → Projects (should show new project)

6. SHARE WITH CUSTOMER
   - Create page with: [gdwb_project_dashboard]
   - Share link with customer
   - They can now: upload files, chat, request revisions

API EXAMPLES
================================================================================

List Projects:
curl -X GET https://yoursite.com/wp-json/gdwb/v1/projects \
  -H "X-WP-Nonce: <nonce>"

Create Project:
curl -X POST https://yoursite.com/wp-json/gdwb/v1/projects \
  -H "X-WP-Nonce: <nonce>" \
  -d '{"title":"New Project","description":"..."}'

Upload File:
curl -X POST https://yoursite.com/wp-json/gdwb/v1/vault/123/upload \
  -F "file=@document.pdf" \
  -H "X-WP-Nonce: <nonce>"

Send Chat Message:
curl -X POST https://yoursite.com/wp-json/gdwb/v1/chat/123/send \
  -H "X-WP-Nonce: <nonce>" \
  -d '{"message":"Hello!","is_private":false}'

Get Analytics:
curl -X GET https://yoursite.com/wp-json/gdwb/v1/stats \
  -H "X-WP-Nonce: <nonce>"
